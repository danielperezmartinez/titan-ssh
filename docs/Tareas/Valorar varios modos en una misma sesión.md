# Valorar varios modos en una misma sesión

## Objetivo

Hoy cada sesión tiene un único modo. Valorar permitir seleccionar varios modos
(SSH, escritorio remoto, mouse pad, SFTP…) en la misma sesión.

## Idea del usuario

En la lanzadera, una sesión con varios modos seleccionados muestra un botón
por cada modo (p. ej. «SSH», «Escritorio»), para abrir directamente el que se
quiera.

## Criterios de finalización

- Revisado cómo se modela hoy el tipo de sesión y qué implicaría pasar a varios.
- Propuesta de UX: cómo se eligen los modos, qué se abre al lanzar la sesión y
  cómo se cambia entre ellos.
- Decisión del usuario; si se implementa, tarea o ADR que lo recoja.
